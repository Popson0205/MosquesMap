# MosqueMap Admin Portal

Full-stack admin dashboard for managing the MosqueMap mosque database.

## Features
- 📊 **Dashboard** — Stats, charts, recent activity
- 🕌 **Mosque Management** — Add, edit, verify, reject mosques
- 📥 **Submissions Review** — Approve or reject community-submitted mosques
- 🗺️ **Map View** — Google Hybrid satellite map of all mosques
- 👥 **User Management** — Admin and mosque admin roles
- ⚙️ **Settings** — App config, password change, CSV export

## Quick Start (Local)

```bash
npm install
cp .env.example .env
# Edit .env with your settings
npm start
# Open http://localhost:3000
```

**Default credentials:**
- Email: `admin@mosquemap.ng`
- Password: `MosqueMap2026!`

## Deploy to Render.com

1. Push this folder to a GitHub repository
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect your GitHub repo
4. Render auto-detects `render.yaml` — click **Create**
5. Set environment variables in Render dashboard:
   - `ADMIN_EMAIL` → your admin email
   - `ADMIN_PASSWORD` → a strong password
   - `SESSION_SECRET` → auto-generated by Render
6. Your portal will be live at `https://your-app.onrender.com`

## Environment Variables

| Variable | Description | Default |
|---|---|---|
| `PORT` | Server port | 3000 |
| `NODE_ENV` | Environment | production |
| `SESSION_SECRET` | Session encryption key | (auto-generated) |
| `ADMIN_EMAIL` | Admin login email | admin@mosquemap.ng |
| `ADMIN_PASSWORD` | Admin login password | MosqueMap2026! |

## Production Database

The current version uses in-memory storage (data resets on restart).
For production, replace `src/data.js` with PostgreSQL + PostGIS:

```bash
# Install PostgreSQL driver
npm install pg

# Connection string in .env
DATABASE_URL=postgresql://user:password@host:5432/mosquemap
```
